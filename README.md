# Recorrido virtual 360

**Ver el recorrido:** https://monicasilvasilva.github.io/recorrido-360-/

Funciona en computador, celular, Google Cardboard y gafas VR (Meta Quest). Con el botón ⬇
se guarda en el dispositivo para verlo sin internet y se puede instalar como app.

Este repositorio contiene el sitio ya publicado (GitHub Pages, rama `main`, carpeta raíz).
Se edita con las herramientas de la carpeta `recorrido/` (`iniciar.bat`) y se sube con
`publicar-github.bat`.
